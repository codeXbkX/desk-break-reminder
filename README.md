# Desk Break Reminder 🧍

I sit at my desk for hours. Some days I wouldn't get up even once, and my lower
back started paying the price - that dull ache that follows you into the evening.
I tried setting phone alarms, but I'd swipe them away without thinking.

So I built this little Windows app to save my own back, and it have helped me a
lot. Now I'm sharing it so anyone who sits too long can use it too.

Every 30 minutes (you choose) it takes over your screen for a few seconds with a
friendly animated character and a nudge to **stand up, stretch, walk, hydrate, or
rest your eyes**. Hard to ignore, easy to dismiss - click anywhere or press any key.

## Get it

1. Download **`DeskBreakReminder.zip`** from the [Releases](../../releases/latest) page.
2. Unzip and double-click **`Install.bat`** (or just run `DeskBreakReminder.exe`).
3. Look for the icon in your system tray, bottom-right. Right-click it for settings.

Windows might show a SmartScreen warning the first time (new, unsigned app) - click
**More info → Run anyway**. It's open source, so you can read exactly what it does.

## Make it yours

Right-click the tray icon to change how often it reminds you, the reminder style,
the color theme, and more. That's it.
